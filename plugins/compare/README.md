# Antes y después

Plugin a pantalla completa que compone una imagen de comparación para compartir:
el **antes** (el archivo original que se abrió, u otra foto que se elige) y el
**después** (la imagen visible).

- Diseños: dividida por una línea (se arrastra sobre la imagen), diagonal,
  lado a lado y arriba y abajo.
- Formatos: como la imagen, 1:1, 4:5, 9:16 y 16:9.
- Línea con grosor, color y tirador; etiquetas «ANTES / DESPUÉS» editables.

El resultado se abre como capa nueva en otra pestaña.
