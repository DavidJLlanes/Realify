# Cambiar color de prendas (`ai.recolorClothes`)

Cambia el color de una prenda en OKLab conservando sus sombras, brillos y pliegues; las prendas blancas, grises o negras se tiñen con el tinte.

Acceso directo al editor de ropa (`plugins/clothing-editor/`) abierto en el grupo «color». Premium 👑, sin interruptor. Resultado: una capa nueva con alfa («Ropa · retoque»).
Mandos: `js/features/clothing/params.js`. Motor: `js/features/clothing/engine/` y `shared/`.
