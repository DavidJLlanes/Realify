# Textura de tejido (`ai.fabricTexture`)

Realza, apaga o devuelve la trama del tejido y rellena las zonas que quedaron demasiado lisas tras planchar o recolorear.

Acceso directo al editor de ropa (`plugins/clothing-editor/`) abierto en el grupo «textura». Premium 👑, sin interruptor. Resultado: una capa nueva con alfa («Ropa · retoque»).
Mandos: `js/features/clothing/params.js`. Motor: `js/features/clothing/engine/` y `shared/`.
