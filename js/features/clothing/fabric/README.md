# Arrugas de telas y fondos (`ai.fabricWrinkles`)

Plancha las arrugas de sábanas, cortinas, manteles o fondos de tela: tocas la tela y se alisa sin perder su trama.

Acceso directo al editor de ropa (`plugins/clothing-editor/`) abierto en el grupo «planchar» y con «Telas y fondos» elegido (se tocan las telas en la foto). Premium 👑, sin interruptor. Resultado: una capa nueva con alfa («Ropa · retoque»).
Mandos: `js/features/clothing/params.js`. Motor: `js/features/clothing/engine/` y `shared/`.
