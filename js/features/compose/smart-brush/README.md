# Pincel inteligente con IA… (`ai.smartBrush`)

Pinta sobre un objeto y la selección se ajusta a sus bordes (MobileSAM). Puedes añadir o quitar; el resultado es la selección activa.

Ventana a pantalla completa compartida con «Selección con un toque» (`js/features/samtools.js`, modo `brush`): el trazo se reparte en hasta 6 puntos para MobileSAM (`puntosDeTrazo`). Premium 👑 sin interruptor. Pruebas: `tests/ia/composicion/`.
