# Informe de realismo (`ai.photoReport`)

Mide nitidez, ruido, rango dinámico, recortes, zonas lisas, metadatos del archivo original y la puntuación de Plausibilidad (`js/analysis/metrics.js`). Se muestra en un diálogo y se guarda en PDF o JSON (`ai-kit/report-host.js`). Motor puro: `realism/engine/informe.js`. Premium 👑, sin modelos.
