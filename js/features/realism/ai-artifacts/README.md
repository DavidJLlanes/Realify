# Manos y dientes sospechosos (`ai.aiArtifacts`)

Avisa (no corrige) de manos con dedos demasiado largos o desiguales, nudillos irregulares o articulaciones imposibles, y de filas de dientes con demasiadas separaciones. Usa los puntos de personas (`js/ai/people/`: cara, pose, manos) y el motor puro `realism/engine/avisos.js`. Resultado: diálogo con el informe, sin tocar la foto. Premium 👑. Son indicios: una mano de perfil o tapada puede dar falsos avisos.
