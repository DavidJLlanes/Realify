# Definición y tono (`ai.bodyTone`)

Realza la definición del cuerpo adulto: relieve de luz y sombra y musculatura por zonas, sin generar piel. No existe para el perfil infantil.

Acceso directo al editor de cuerpo (`plugins/body-editor/`) abierto en el grupo «definicion». Premium 👑, sin interruptor. Resultado: una capa nueva por persona.
Mandos y perfiles: `js/features/body/params.js` y `js/ai/people/profiles.js`. Motor: `js/features/body/engine/` y `js/features/body/definition/`.
