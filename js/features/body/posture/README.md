# Postura (`ai.bodyPosture`)

Endereza la postura: erguir la espalda, cuello adelantado y hombros caídos. Cambios pequeños y naturales, con el perfil de la persona.

Acceso directo al editor de cuerpo (`plugins/body-editor/`) abierto en el grupo «postura». Premium 👑, sin interruptor. Resultado: una capa nueva por persona.
Mandos y perfiles: `js/features/body/params.js` y `js/ai/people/profiles.js`. Motor: `js/features/body/engine/` y `js/features/body/definition/`.
