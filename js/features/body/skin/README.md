# Piel del cuerpo (`ai.bodySkin`)

Piel del cuerpo: suavizar, uniformar el color y bronceado (adultos); el perfil infantil solo tiene «uniformar».

Acceso directo al editor de cuerpo (`plugins/body-editor/`) abierto en el grupo «piel». Premium 👑, sin interruptor. Resultado: una capa nueva por persona.
Mandos y perfiles: `js/features/body/params.js` y `js/ai/people/profiles.js`. Motor: `js/features/body/engine/` y `js/features/body/definition/`.
