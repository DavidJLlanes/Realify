# Mis estilos (`ai.myStyles`)

Guarda como estilo las estadísticas de color y tono (OKLab, por zonas) de una foto de referencia: unos cientos de bytes en este navegador (`localStorage`). Se aplican a la foto actual o a **todas las fotos abiertas**, y se pasan a otra persona como archivo `.realify-estilo.json` (exportar / importar, con validación). Premium 👑. Solo estilos de color y tono; los estilos de cámara son capas de filtro reeditables (`ai.cameraPacks`). Pruebas: `tests/ia/estilo/`.
