# Packs de cámara (`ai.cameraPacks`)

Tres packs (Película, Móvil, Réflex y óptica) que agrupan las cámaras de `plugins/cameras` en un solo selector. Se aplican con el motor de Cámaras y quedan como **capa de filtro reeditable** (`camaras`): se pueden reabrir y «Aplicar esta edición a otras fotos» las copia a un lote. Premium 👑 (motor Premium activado). Pruebas: `tests/ia/estilo/`.
